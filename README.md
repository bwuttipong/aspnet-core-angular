# aspnet-core-angular 🚀

Learning project: build an app with **ASP.NET Core** (backend API) + **Angular** (frontend SPA), from scratch.

## Planned structure

| Folder | What it is |
|--------|------------|
| `server/` | ASP.NET Core Web API project (`.NET 10`) |
| `client/` | Angular SPA (`ng new`) |

## Getting started

```bash
# backend
cd server
dotnet run

# frontend (in another terminal)
cd client
npm install
ng serve
```

> Scaffold the actual projects with `dotnet new webapi -o server` and
> `ng new client` once the course gets to that step.
