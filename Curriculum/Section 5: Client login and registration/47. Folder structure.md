And what're going to utilize is Ng generates which allows us to generate components.
but we can shorthand this and we can say:
```bash
ng g --help
```

To generate component:

ng g c

One of them that do wish to look at:
- --dry-run         Run through and reports activity without writing out result.
- --skip-tests      Skip the generation of unit test files `spec.ts`

we can specify how we want these things to be created.
So let's open up the angular dot JSON file.
And inside there towards the top we have a schematics section.

```json
      "schematics": {
        "@schematics/angular:component": {
          "skipTests": true,
          "path": "src"
        }
      },
```

Go back to the terminal once again, lets just repeat the command:

```bash
ng g c layout/nav
```
