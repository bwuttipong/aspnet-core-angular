### BUILDING A WAKLING SKELETION PART ONE - API

#### WHAT IS A WALKING SKELETON?

A Walking Skeleton is a tiny implementation of the system that performs a small end-to-end function. It need not use the final architecture, but it should link together he main architectural components.

The architecture and the functionality can then evolve in parallel.

#### LEARNING GOALS

Implement the basic APIfunctionality and have an intruductory understanding of:

    1. Using the dotnet CLI
    2. API Controllers and Endpoints
    3. Entity Framwork
    4. The API Project structure
    5. Configuration and Environment variables
    6. Source control

#### Summarize this lecture

In the lecture titled "Introduction," we focus on the concept of a "walking skeleton," which represents a foundational implementation of a system that can perform a basic end-to-end function. The primary goal is to create a simple API project that interfaces with a database, enabling us to fetch and display data in a client-side Angular application.

Key points covered in this lecture include:

    1. Learning Objectives: We aim to implement basic API functionality and get familiar with the .NET command line interface, which is crucial for creating new .NET applications using templates.

    2. API Structure: The lecture explores the structure of API controllers and endpoints, providing insight into their roles within the application.

    3. Entity Framework Introduction: We introduce Entity Framework, which will be elaborated on in future lectures, explaining how it aids in database interactions.

    4. Project Structure: We examine the overall structure of the API project, including the startup process for the .NET application and the configuration settings alongside environment variables.

    5. Source Control: Finally, once we have a functioning application, we discuss the importance of committing our code to source control, ensuring a backup and version history of our progress.

This foundational knowledge prepares us for adding more complexity to our application in subsequent lessons. If you have any questions or need clarification on any part, feel free to ask!
